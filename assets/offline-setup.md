使用浏览器或下载工具下载一个 GGUF 文件，保留原文件名；在软件的查询与翻译设置中点击“安装已下载的模型文件”。软件在本机校验并配置，不需要自己填写路径。旧版此按钮位于“完全离线安装与模型目录”中。

## 推荐：一键下载并启用

1. 打开 **设置 → 查询与翻译 → 离线模型安装**。
2. 推荐选择 **Hy-MT2 Q8 → 下载并启用**；磁盘或内存有限可选择 Q6，只需要一个模型。
3. 软件显示已下载大小、百分比和独立校验进度，自动安装到默认共享目录，再选用该模型。启用离线翻译并按预加载设置准备，无需手动找路径或移动文件。

关闭设置页后下载继续；可暂停，网络异常后点击“继续下载并启用”。退出软件会暂停并保留部分文件，下次启动再次点击下载即可续传。服务不支持 Range 时会安全地从头下载；已有完整但未校验的临时文件直接校验，不重复下载。

下载使用与软件更新相同的网络模式，但使用独立连接会话。连接异常时可检查系统代理，或在软件更新的网络选项中选择合适模式后重试。不会索取模型站账号或发送 AI 服务凭据。Q8 提供腾讯CNB源、GitHub源及腾讯模型原始源的固定文件链接，Q6 当前使用原始源。v0.39.16 可在软件中选择模型来源；旧版也可使用上方链接在浏览器下载，再选择本地安装。均为同一固定型号与版本。

自动安装位置为 `软件默认共享模型目录`，供同一系统用户下的 LingoLeap 本地账号共享。常见根目录为 macOS `~/Library/Application Support/lingoleap/translation-models/`、Windows `%APPDATA%/lingoleap/translation-models/`，**以设置中显示的默认安装目录为准**。不会尝试向可能不可写的应用安装目录自动塞入权重。

原始数据边下载边写入摘要对应的 `.part` 文件，不在内存中缓存整份模型。仅在全部字节及 SHA-256 验证成功后原子更名为 GGUF；损坏下载会清理并提示重下，不覆盖既有可用文件。无需再存一份完整副本，下载前检查剩余磁盘空间，建议至少预留约 2.1 GB 给 Q8。

## 完全离线部署：先准备两个文件

离线电脑不需要登录账号、API Key、Python、Ollama、Node.js 或包管理器。需要预先准备：

- 对应系统和架构的 **完整应用包**：macOS Apple Silicon / Windows x64。首次安装使用完整应用包，不使用缺少词典的纯程序更新包。
- 下表的一个 **固定版本 GGUF 模型文件**，默认推荐 Q8；Q6 为较小备选。保留原文件名，不下载整个模型仓库。

在可联网的电脑下载好这两个文件，通过 U 盘、移动硬盘或局域网复制到离线电脑。模型与程序平台无关，同一个 GGUF 可用于 Mac 和 Windows；应用包和引擎必须匹配操作系统与架构。下载地址见下方“模型文件”。

### 方式 A：随程序放置，不经过导入

Mac：解压应用，放入 `/Applications` 或其他可写位置。`LingoLeap.app` 与 `LingoLeap-models` 文件夹并排；不要把 GGUF 放进 `.app` 内部。

```text
/Applications/
  LingoLeap.app
  LingoLeap-models/
    Hy-MT2-1.8B-Q8_0.gguf
```

Windows：解压完整程序文件夹，保留全部 DLL、`resources` 等随包文件。在 `LingoLeap.exe` 所在文件夹中建立 `LingoLeap-models`。

```text
D:\Apps\LingoLeap\
  LingoLeap.exe
  resources/
  …其他随包文件…
  LingoLeap-models/
    Hy-MT2-1.8B-Q8_0.gguf
```

选择 Q6 时将文件换成 `Hy-MT2-1.8B-Q6_K.gguf`，不需要两个都下载。目录名称及模型文件名保持一致。先放好文件再启动，软件自动发现；只有 Q6 时自动选择 Q6。软件已打开时，在设置中点击“重新扫描模型”，扫描后会选用可用型号。文件放错目录或摘要不符时会明确提示，不会偷偷使用在线 AI。

移动应用时一并移动 `LingoLeap-models` 文件夹。此方式不把模型复制到共享目录，适合 U 盘部署和多人分发；系统对应用本身的运行权限要求仍然适用。

### 方式 B：在离线电脑安装已下载文件

1. 启动程序，打开 **设置 → 查询与翻译 → 完全离线安装与模型目录**。
2. 点击 **安装已下载的模型文件**，选择准备好的 GGUF。
3. 软件在本机校验并复制到默认共享目录，自动选用；整个过程不联网。

此方式需要保留源文件并写入一份模型，安装时相应多占用一份磁盘空间；成功后可自行移走源文件。后续更新或移动程序不需要重新安装共享模型。也可以“打开共享目录”后手动放入原名 GGUF，再重新扫描。

### 断网验收与使用边界

断开网络后启动软件，确认查询与翻译显示可用型号并完成本地准备，然后输入一句中、英或韩语进行离线翻译；本地词典、截图、贴图和随包 OCR 同样不依赖在线 AI。截图权限仍需按系统提示允许。AI 翻译、AI 讲解、问答和在线更新需要联网；完全离线部署保持 AI 调用策略为默认手动即可。韩语朗读取决于系统是否已安装相应语音，需语音时请在联网准备阶段安装。
