# LingoLeap 语跃 · 官方发布

面向中文母语者的桌面韩语理解、表达和学习积累工具。

- 官网：https://smalbox.github.io/LingoLeapOfficial/
- 下载及版本记录：https://github.com/SmalBox/LingoLeapOfficial/releases
- 签名更新清单：`updates/stable.json`
- 发布公钥和身份信息：`updates/trust.json`
- 使用反馈：https://github.com/SmalBox/LingoLeapOfficial/issues

程序包与内容包放在 Releases，网站与公开版本配置保存在本仓库。客户端内置发布公钥，不从网络动态信任任意新密钥。

当前为测试版：macOS 程序 ZIP 暂未签名、公证，需退出旧版本后手动替换；内容资源可在应用中确认更新并回退。仅提供已实际构建的平台，不将其他平台标为已验证。

维护说明见 [PUBLISHING.md](PUBLISHING.md)。本仓库不保存 API Key、访问令牌、签名私钥或用户资料。

国内发行与更新：<https://cnb.cool/DipSugar/LingoLeapOfficial>。v0.14.0 起设置中可明确选择国内 CNB 或 GitHub。
